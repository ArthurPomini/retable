**ReTable** is a tool designed to help manipulate data in large tables.

You know that moment when you try to upload a table to a spreadsheet, and an alert pops up saying, *"Table too large, remove rows/columns to load"*? Well, with ReTable, you can remove as many rows or columns as you need to shrink your table down to size.

Table Reductor is a tool designed to help you handle data from large tables.

You know that moment when you try to upload a table to a spreadsheet and get an error saying, "Table too large, remove rows/columns to load"? With Table Reductor, you can easily remove as many rows or columns as needed to reduce the size of your file.
