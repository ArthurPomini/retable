# ReTable

**ReTable** is a tool designed to help manipulate data in large tables.

You know that moment when you try to upload a table to a spreadsheet, and an alert pops up saying, *"Table too large, remove rows/columns to load"*? Well, with ReTable, you can remove as many rows or columns as you need to shrink your table down to size.

---

## How to Run

### Prerequisites

- **Python 3.8+**
- **Tkinter** (included by default with Python on Windows and macOS).
  - On Linux (Ubuntu/Debian), if not already installed:
    ```bash
    sudo apt install python3-tk
    ```

> [!NOTE]
> No external dependencies are required (`pip install`). The project is built entirely using Python's standard library.

---

### Step by Step

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arthurpomini/retable.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd retable
   ```

3. **Launch the application:**
   ```bash
   python main.py
   ```
   *(or `python3 main.py` depending on your environment)*
